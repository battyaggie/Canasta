# People at the 3D table

`man.glb` and `woman.glb` are made from models by **Quaternius** (https://quaternius.com), released under
**CC0 1.0** (public domain, https://creativecommons.org/publicdomain/zero/1.0/):

- Universal Base Characters: `Regular_Male_FullBody`, `Regular_Female_FullBody`, `Hair_SimpleParted`, `Hair_Ponytail`
- Modular Outfits Fantasy: the Peasant outfit (body, legs, feet, arms; the woman without the arm pieces, so no gloves)

Changes: each body, outfit and hair style merged into one file on one skeleton, textures shrunk to JPEG,
normal/roughness maps removed, the skin texture is the light tone (other tones are a colour tint at run time).
No credit is required by the licence; this note is here so the source is easy to find.
